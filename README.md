# Employee Leave Management System

## Project Overview
Employee Leave Management System is a Java web application developed to manage employee leave requests efficiently.

Employees can:
- Login
- Apply Leave
- View Leave Records

Admin can:
- Approve Leave
- Reject Leave

---

## Technologies Used

### HTML
Used to structure web pages and forms.

Examples:
- Login Form
- Leave Application Form
- Dashboard Layout
- Navigation Buttons

### CSS
Used to create corporate and professional UI design.

Features:
- Professional Login Page
- Dashboard Styling
- Buttons & Navigation Bar
- Responsive Layout
- Corporate Theme

### JSP (JavaServer Pages)
Used to create dynamic web pages.

Examples:
- login.jsp
- dashboard.jsp
- leaveForm.jsp
- viewLeaves.jsp

### Servlets
Used to handle request processing and application logic.

Examples:
- LoginServlet
- LeaveServlet
- ApproveLeaveServlet
- RejectLeaveServlet

### JDBC
Used to connect Java application with MySQL database.

Operations:
- Database Connection
- Login Validation
- Insert Leave Request
- Update Leave Status

### MySQL
Used for storing employee and leave data.

### Apache Tomcat
Used as the application server.
